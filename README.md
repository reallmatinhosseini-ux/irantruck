# Iran Truck Trading Group — website

Static site for Iran Truck Trading Group, official representative of LEO in Iran.

- `index.html` — the page
- `css/style.css` — styles
- `js/main.js` — interactions and motion (GSAP, ScrollTrigger and Lenis load from CDNs)
- `images/` — photography and logos

No build step: open `index.html` or serve the folder with any static host (GitHub Pages works as-is).

Stock photography (`images/st-*`, `images/lx-*`) is from Unsplash under the Unsplash License.
